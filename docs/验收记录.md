## 9. 未验证与风险

- 真实异地两台物理设备联机：未验证。本机条件只有同机双浏览器，以及经公网 URL 回环的端到端测试。
- Cloudflare 临时隧道地址每次重启都变化：依赖 `start.ps1` 自动同步；同步后 Pages 有 CDN 缓存窗口（实测数分钟内可能仍返回旧地址），旧地址失效时需等缓存刷新或刷新页面。
- GitHub Pages 自身在本机偶发连不上（TLS 握手失败），验收时用无头 Chromium 加 `--no-proxy-server` 完成；这是本机网络/代理环境问题，不是页面问题。
- 本机到 github.com 的 TLS 间歇失败，`git push` 需要 `-c http.proxy=` 绕过；`gh` 走 API 正常。
- 未做并发压测、长时间运行测试；SQLite 为单文件、未启用 WAL。
- 二进制来源：`cloudflared` 使用官方 2026.8.2 版本，SHA256 `c29eee2b121f5436a642eed69fd9767da7e7b8c510fa50aaa130337f931357b5`，与 GitHub 官方 release 资产 digest 一致（经 npm 镜像包获取后校验）。
- 清理本机遗留进程时，早期的宽松匹配规则误停过两条其他本地开发服务进程（`node server/index.js`，端口 4394 / 4520），只结束了进程、没有改动任何文件；现已把停止脚本收紧为只匹配本项目绝对路径 `pinecone-club` 与 4460 隧道。
- 20 款游戏全部有引擎测试与视图挂载检查，但每个玩法的深度平衡（尤其策略类）只做了规则级验证，没有真人长期对局数据。
