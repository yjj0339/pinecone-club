# PINECONE CLUB · 松果游戏社

两个人、两台设备、二十款小游戏。开一间房，把六位房号或邀请链接发给朋友，双方点准备后同步开局。

这个项目是在 `D:\codexAI\pinecone-club` 里从零重写的独立版本：全新的名字、全新的纸品视觉、全新的引擎与视图实现，不读取、不复用本机任何旧项目文件。

## 有什么

- 20 款双人小游戏：五子棋、雾中舰队、点格领地、黑白棋、雷区漫步、记忆翻牌、灵光问答、2048 对决、数独竞速、回声序列、桌面冰球、铁皮坦克、泡泡爆破、长蛇竞技、落块对战、弹弓攻城、迷宫夺旗、石头剪刀布、抢拍反应、打字竞速。
- 大厅选游戏 → 开房/用房号加入 → 双方准备 → 3 秒倒计时同步开始 → 对局 → 结算 → 再来一局 / 换游戏 / 回大厅。
- 系列赛 1 / 3 / 5 局，服务端记录系列比分。
- 服务端权威：所有操作在服务端校验与结算，客户端只发操作；断线冻结计时，60 秒内回来继续，超时判负。
- 懒加载房间列表、房间号 + 邀请链接、实时延迟显示、表情、本机战绩、音效开关。
- 浅色纸品视觉系统（`--tw-paper` / `--tw-coral` / `--tw-forest`），所有插画都是手写 SVG，20 张卡片各不相同。

## 一键启动（Windows / D 盘）

1. 双击 `启动松果游戏社.cmd`
2. 等窗口打印「PINECONE CLUB 已启动」，会给出本机地址和公网地址
3. 把公网地址发给朋友，或把邀请链接发给对方
4. 结束服务双击 `停止松果游戏社.cmd`

脚本会：构建前端 → 启动 Node + Socket.IO 服务（端口 4460）→ 启动 Cloudflare 临时隧道 → 把隧道地址写进 `server-url.json` 并同步到线上页面。

- GitHub Pages：https://yjj0339.github.io/pinecone-club/

## 本机开发

```powershell

npm install
npm run dev        # Vite 开发服务器（5173）
```

## 目录

```
client/            前端：外壳、大厅、房间、对局、样式、美术、音效
server/            Socket.IO 权威服务端：房间、回合、断线、结算、SQLite 战绩
shared/            游戏目录、协议常量
games/<id>.engine.js  纯函数引擎：create / act / step / view
games/<id>.view.js    视图：mount(root, api) → { update, unmount }
tests/             引擎与房间测试
qa/                真双客户端联机冒烟脚本
scripts/           启动 / 停止 / 发布脚本
docs/              设计契约、制作提示词、验收记录
```

## 规则与边界

- 只允许两人一间房，房号六位数字；房间关闭后房号立即失效。
- 对局状态完全由服务端持有；刷新页面会通过本机保存的身份牌自动回到原座位。
- 只有在 `runtime/state.json` 记录的服务和隧道会被停止脚本处理，不会碰机器上其他项目。
- 首次启动需要联网下载 `cloudflared`（约 30MB，存放在 `runtime/bin`）。
